Sync with GitHub

Your log is kept in a JSON file in a private repository. Every device with these details stays in step, and GitHub keeps a full version history of every change.

  1. Create a private repo — github.com/new. An empty one is fine.
  2. Make a fine-grained token at Settings → Developer settings → Personal access tokens → Fine-grained.
  3. Under Repository access pick only that repo. Under Permissions → Repository permissions set Contents to Read and write. Nothing else.
  4. Copy the token and paste it below.

The token is stored on this device only, and gives access to that one repository. Anyone who can unlock this phone could read it. Use a token scoped to a single private repo — never one with wider access — and revoke it on GitHub if the device is lost.

Set up another device

This link carries the repository, the file path and the access token. Whoever opens it in Safari gets the app fully connected — nothing to type, and the details are wiped from their address bar straight away.

Treat this like a password. Send it one-to-one, ask them to tell you when it works, then delete the message from both sides. Give each person their own token so you can revoke one without disturbing the other.
